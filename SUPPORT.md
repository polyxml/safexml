# Support Resources for SafeXML

Welcome to the **SafeXML** community! Here is how to find help, report issues, and participate in discussions.

---

## 1. Documentation

Before filing an issue, please check the official documentation:
- **PyPI Package**: [https://pypi.org/project/safexml/](https://pypi.org/project/safexml/)
- **GitHub Repository & Guide**: [https://github.com/polyxml/safexml#readme](https://github.com/polyxml/safexml#readme)
- **PolyXML Organization**: [https://github.com/polyxml](https://github.com/polyxml)

---

## 2. GitHub Discussions

For general questions, architecture questions, migration questions from `defusedxml`, or integration advice:
- Visit [GitHub Discussions](https://github.com/polyxml/safexml/discussions).

---

## 3. Reporting Bugs & Regressions

If you encountered a bug, unexpected parsing behavior, or performance regression:
- Open a bug report on [GitHub Issues](https://github.com/polyxml/safexml/issues).
- Please include a minimal XML document and Python code snippet that reproduces the issue.

---

## 4. Security Inquiries

For vulnerability reports or security bypass disclosures, do **not** use the public issue tracker. Please consult our [Security Policy](SECURITY.md) or submit a report via [GitHub Private Vulnerability Reporting](https://github.com/polyxml/safexml/security/advisories/new).
